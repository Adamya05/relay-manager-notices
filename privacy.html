manager — Privacy notice

Updated September 29, 2026. This notice describes the current Instagram API capability assessment performed with the Meta app named manager. It does not describe a publicly available production messaging service.

Purpose and contact

Adamya Nagpal uses this app to assess authorized Instagram professional-account access for Relay. Questions or deletion requests can be sent to adamya.nagpal2000@gmail.com.

Information processed

With the account owner's authorization, the assessment reads account identity and available conversation and message metadata from Meta. This can include account and participant identifiers, usernames, conversation and message identifiers, timestamps, and available API field names. Some API responses may include message content; private message content is not included in the assessment report.

Use and retention

Access is used to establish which API capabilities work and what information they expose. Diagnostic reads are bounded. Private response values are processed in memory; the assessment retains response statuses, counts, field names, numeric API errors, configuration findings, and coverage limits. It does not retain message bodies or private participant, conversation, or message identifiers in the report.

The authorized account's access token is stored in private local configuration on the operator's computer. Credentials are excluded from public source code and the assessment report. Diagnostic reports may remain as a technical record. The current assessment does not send Instagram messages or automatically create Relay leads, and does not maintain a message-content database.

Providers and scope

Meta processes account authorization and Instagram API requests under its own policies. These static notices do not require an Instagram login and do not receive access tokens or Instagram messages. Their hosting provider may process ordinary website request information under its own policies. The current manager assessment has no active webhook receiver. Any future ongoing message intake, additional processing provider, or production use requires an updated notice and appropriate account authorization.

Control and deletion

The account owner can remove the app's access through Instagram's Apps and Websites settings. Contact the operator to stop the assessment and request removal of locally stored account credentials. Identify the connected account privately; do not send a password or access token. The current diagnostic retains no message-body archive to delete. Removing this app's access or local credentials does not delete the original Instagram messages or records held independently by Meta.
