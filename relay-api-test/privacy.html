Relay API Test — Privacy notice

Updated September 29, 2026. This notice describes the controlled Instagram API capability test operated by Adamya Nagpal. It does not describe a production messaging service.

Purpose and contact

The test checks authorized access to one connected Instagram professional account's conversations and message details. Questions and deletion requests can be sent to adamya.nagpal2000@gmail.com.

Information processed

With the account owner's authorization, the test reads account identity, conversation and message metadata, and any message content needed to inspect API capability. This may include usernames, participant, conversation, and message identifiers, timestamps, message text, and available fields. The app does not send replies. If webhook delivery is enabled for a diagnostic session, Meta events may also include message text or attachments, which the receiver must briefly process to authenticate delivery and inspect structure. It does not download attachments.

Use and retention

Private API response values are processed in memory for bounded diagnostic reads. The technical assessment retains response statuses, counts, field names, numeric errors, configuration findings, and coverage limits. It does not retain message bodies, attachments, or private participant, conversation, or message identifiers in files or a database. The access token is stored in private local configuration and excluded from this public repository. Diagnostic reports may remain as a technical record.

Providers and scope

Meta provides account authorization and API data. These static notice pages do not receive access tokens or Instagram messages; their hosting provider may process ordinary website traffic. If a temporary Cloudflare Tunnel is enabled for a webhook session, Cloudflare carries that request traffic, including payload content in transit. Provider processing is governed by their respective policies. Ongoing intake or production use requires an updated notice.

Control and deletion

The account owner can remove Relay API Test-IG access in Instagram's Apps and Websites settings. Contact the operator to stop the test and request removal of locally held credentials. Identify the connected account privately; do not send a password or token. The test retains no message-content archive to delete. Revoking access does not delete original Instagram messages or independent provider records.
